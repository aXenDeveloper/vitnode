---
title: Data Table
description: Powerful table compatible with SSR, search, pagination and more.
---

Data Table is a powerful table component build with scratch for VitNode. It's compatible with SSR, search, pagination and even in query state from the URL.

## Preview

import { PreviewComponent } from '@/components/fumadocs/preview-component';
import { DataTable } from 'vitnode-frontend/components/ui/data-table';

<PreviewComponent>
  <DataTable
    className="w-full"
    data={[
      { id: 1, name: 'John Doe' },
      { id: 2, name: 'Jane Doe 2' },
    ]}
    columns={[
      { title: 'ID', id: 'id' },
      { title: 'Name', id: 'name' },
    ]}
    defaultSorting={{
      sortBy: 'id',
      sortDirection: 'desc',
    }}
  />
</PreviewComponent>

#### Actions

We created special column for actions. You can add buttons, links or any other components. Flex is used for the layout with gap.

```tsx
<DataTable
  data={[
    { id: 1, name: 'John Doe' },
    { id: 2, name: 'Jane Doe 2' },
  ]}
  columns={[
    { title: 'ID', id: 'id' },
    { title: 'Name', id: 'name' },
    {
      id: 'actions', // [!code ++]
      cell: ({ row }) => {
        return (
          <>
            <Button>Edit</Button>
            <Button>Delete</Button>
          </>
        );
      },
    },
  ]}
  defaultSorting={{
    sortBy: 'id',
    sortDirection: 'desc',
  }}
/>
```

## Usage with Pagination API

  You can read how to implement [Pagination API

import { Step, Steps } from 'fumadocs-ui/components/steps';
 
<Steps>
<Step>

### Get data from API

Create `getData` function and privide in it the [`fetcher`](/docs/ui/fetch) function.

```tsx title="example.tsx"
import { fetcher } from 'vitnode-frontend/api/fetcher';

const getData = async (query: ShowLanguagesAdminQuery) => {
  const { data } = await fetcher<
    ShowLanguagesAdminObj,
    ShowLanguagesAdminQuery
  >({
    url: '/admin/core/languages',
    query,
    cache: 'force-cache',
  });

  return data;
};
```

</Step>

<Step>

### Create the view

Create the view function with `searchParams` argument.

```tsx title="example.tsx"
import { SearchParamsPagination } from 'vitnode-frontend/helpers/get-pagination-tool';

export const LangsCoreAdminView = async ({
  searchParams,
}: {
  searchParams: Promise<SearchParamsPagination>;
}) => {
  return <></>;
};
```

</Step>

<Step>

### Get data with getPaginationTool

Use the `getPaginationTool` function to get the data and pagination information.

```tsx title="example.tsx"
import {
  SearchParamsPagination,
  getPaginationTool, // [!code ++]
} from 'vitnode-frontend/helpers/get-pagination-tool';

export const LangsCoreAdminView = async ({
  searchParams,
}: {
  searchParams: Promise<SearchParamsPagination>;
}) => {
  // [!code ++]
  const variables = await getPaginationTool({
    searchParams, // [!code ++]
    // [!code ++]
  });
  // [!code ++]

  const data = await getData(variables); // [!code ++]

  return <></>;
};
```

The `getPaginationTool()` function will automatically handle the pagination, search and sorting for you when you're using the `DataTable` component.

</Step>

<Step>

### Data Table

```tsx title="client-example.tsx"
'use client';

export const ContentLangsCoreAdmin = ({
  edges,
  page_info,
}: ShowLanguagesAdminObj) => {
  return (
    <DataTable
      data={edges} // [!code highlight]
      columns={[
        { title: 'ID', id: 'id' },
        { title: 'Name', id: 'name' },
      ]}
      defaultSorting={{
        sortBy: 'created_at',
        sortDirection: 'asc',
      }}
      pageInfo={page_info} // [!code highlight]
    />
  );
};
```

</Step>

<Step>

### Import DataTable into RSC

```tsx title="example.tsx"
import { ContentLangsCoreAdmin } from './client-example'; // [!code ++]

export const LangsCoreAdminView = async ({
  searchParams,
}: {
  searchParams: Promise<SearchParamsPagination>;
}) => {
  return <></>; // [!code --]
  return <ContentLangsCoreAdmin {...data} />; // [!code ++]
};
```

</Step>

</Steps>

<Callout title="Pagination Required" type="warn">
  Sorting system is based on
  [Pagination](/docs/ui/data-table#usage-with-pagination-api). Please make sure
  you have implemented the pagination system before using the sorting system.
</Callout>

<Steps>

<Step>

### Provide enum in getPaginationTool

```tsx title="example.tsx"
import { ShowExampleWelcomeSortEnum } from 'shared/plugins/{your_plugin_code}/example.enum'; // [!code ++]

const variables = await getPaginationTool({
  searchParams,
  sortEnum: ShowExampleWelcomeSortEnum, // [!code ++]
});
```

</Step>

<Step>

### Set columns to sortable

```tsx title="client-example.tsx"
<DataTable
  data={edges}
  columns={[
    { title: 'ID', id: 'id' },

  ]}
  defaultSorting={{
    sortBy: 'created_at',
    sortDirection: 'asc',
  }}
  pageInfo={page_info}
/>
```

</Step>
