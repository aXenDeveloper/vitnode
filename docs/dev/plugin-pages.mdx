title: Plugin Pages

Creating a new page in VitNode is the same as creating a new page in [Next.js](https://nextjs.org/docs/app/building-your-application/routing). The only difference is that you need to create a page inside a plugin folder.

## Pre-build Layouts

Inside `apps/frontend/src/app` directory, you can find pre-build layouts created by VitNode:

| Path                           | Body HTML | i18n | Layout | Session User | Session Admin |
| ------------------------------ | --------- | ---- | ------ | ------------ | ------------- |
| `app/[locale]/(main)/(layout)` | ✅        | ✅   | ✅     | ✅           | ❌            |
| `app/[locale]/(main)`          | ✅        | ✅   | ❌     | ✅           | ❌            |
| `app/[locale]/admin/(auth)`    | ✅        | ✅   | ✅     | ❌           | ✅            |
| `app/[locale]/admin`           | ✅        | ✅   | ❌     | ❌           | ❌            |
| `app/[locale]/`                | ✅        | ✅   | ❌     | ❌           | ❌            |
| `app/`                         | ❌        | ❌   | ❌     | ❌           | ❌            |

## Create a New Page

import { Step, Steps } from 'fumadocs-ui/components/steps';

<Steps>
<Step>

### Create a folder

According to the pre-build layouts, you need to create a folder with `{plugin_code}` inside one of pre-build layouts. For example, if you want to create a new page inside the `(layout)` layout, you need to create a folder inside `app/[locale]/(main)/(layout)/{plugin_code}` directory.

<Callout type="info" title="Plugin folder">
  It is very important to create a folder with the same name as the plugin code.
  Otherwise, the page will not be exported while exporting the plugin.
</Callout>

Of course fell free to create new pages with different names, but it is recommended to use the plugin code as the folder name.

</Step>

<Step>

### Create a page.tsx file

Inside the `{plugin_code}` folder, create a `page.tsx` file. This file will be the main file for the new page.

```tsx title="apps/frontend/src/app/[locale]/(main)/(layout)/{plugin_code}/page.tsx"
export default function Page() {
  return <div>Hello World</div>;
}
```

Follow the [Next.js documentation](https://nextjs.org/docs/app/building-your-application/routing) to find more about creating pages & layouts.

</Step>

</Steps>
