We're using [@nestjs/schedule](https://docs.nestjs.com/techniques/task-scheduling) to schedule tasks. CRON is a time-based job scheduler in Unix-like operating systems. It enables users to schedule jobs (commands or scripts) to run periodically at fixed times, dates, or intervals.

## Usage

Create a service for cron jobs.

import { Step, Steps } from 'fumadocs-ui/components/steps';

<Steps>
<Step>

```ts title="clear.cron.ts"
import { Injectable } from '@nestjs/common';
import { Cron } from '@nestjs/schedule'; // [!code ++]

@Injectable()
export class ClearCoreMembersCron {
  // [!code ++]
  @Cron('45 * * * * *', {
    // [!code ++]
    name: 'ExampleCron',
    // [!code ++]
  })
  exampleCron() {
    console.log('Called when the current second is 45');
  }
}
```

</Step>
<Step>

Register the service in your module `providers` array.

```ts title="members.module.ts"
import { Module } from '@nestjs/common';

import { ClearCoreMembersCron } from './clear.cron'; // [!code ++]

@Module({
  providers: [ClearCoreMembersCron], // [!code ++]
})
export class CoreMembersModule {}
```

</Step>
</Steps>

## CRON Expression

The `@Cron()` decorator supports the following standard cron patterns:

Asterisk (e.g. `*`)
Ranges (e.g. `1-3,5`)
Steps (e.g. `*/2`)

```bash
* * * * * *
| | | | | |
| | | | | day of week
| | | | months
| | | day of month
| | hours
| minutes
seconds (optional)
```

Or you can use a `CronExpression` enum.

```ts title="clear.cron.ts"
import { Injectable } from '@nestjs/common';
import { Cron, CronExpression } from '@nestjs/schedule'; // [!code ++]

@Injectable()
export class ClearCoreMembersCron {
  // [!code ++]
  @Cron(CronExpression.EVERY_30_SECONDS, {
    name: 'ExampleCron',
  })
  exampleCron() {
    console.log('Called every 30 seconds');
  }
}
```
