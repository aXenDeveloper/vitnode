Creating plugins allows you to extend the functionality of VitNode like new pages, routes, and services.

<Callout type="info" title="Development only">
  This guide requires [Dev Server](/docs/dev/install#start-dev-server) to be
  running.
</Callout>

import { Step, Steps } from 'fumadocs-ui/components/steps';

<Steps>
<Step>

## Open create plugin dialog

Open AdminCP and navigate to the `Plugins` page and click on the `Create Plugin` button.

import { ImgDocs } from '@/components/fumadocs/img';
import createPlugin from '@/assets/dev/plugins/create_plugin.png';

<ImgDocs src={createPlugin} alt="Create Plugin button in AdminCP" />

</Step>
<Step>
## Fill the form

Fill the form with your plugin details and click on the `Save` button.

</Step>

<Step>

## Done!

Your plugin is created and you can start developing it.

</Step>
</Steps>
