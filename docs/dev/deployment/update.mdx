## Update VitNode

VitNode works as NPM package, so you can update it using the following command:

import { Tab, Tabs } from 'fumadocs-ui/components/tabs';

<Tabs groupId='package-manager' persist items={['pnpm', 'npm']}>

```bash tab="pnpm"
pnpm add eslint-config-typescript-vitnode@latest -w && pnpm add eslint-config-typescript-vitnode@latest vitnode-frontend@latest vitnode-shared@latest --filter frontend && pnpm add eslint-config-typescript-vitnode@latest vitnode-backend@latest vitnode-shared@latest --filter backend && pnpm add eslint-config-typescript-vitnode@latest vitnode-shared@latest --filter shared
```

```bash tab="npm"
npm i eslint-config-typescript-vitnode@latest && npm i eslint-config-typescript-vitnode@latest vitnode-frontend@latest vitnode-shared@latest --workspace=frontend && npm i eslint-config-typescript-vitnode@latest vitnode-backend@latest vitnode-shared@latest --workspace=backend && npm i eslint-config-typescript-vitnode@latest vitnode-shared@latest --workspace=shared
```

</Tabs>

Packages has a script that will update the database, update the files, create a migration etc.

Sometimes in our [patch notes](https://github.com/VitNode/vitnode/releases) we will mention that you need to update a specific package for example `next` or `react` to a specific version.

### Canary

If you want to use the canary version, you can use `@canary` tag.

  <Tabs groupId='package-manager' persist items={['pnpm', 'npm']}>

```bash tab="pnpm"
pnpm add eslint-config-typescript-vitnode@canary -w && pnpm add eslint-config-typescript-vitnode@canary vitnode-frontend@canary vitnode-shared@canary --filter frontend && pnpm add eslint-config-typescript-vitnode@canary vitnode-backend@canary vitnode-shared@canary --filter backend && pnpm add eslint-config-typescript-vitnode@canary vitnode-shared@canary --filter shared
```

```bash tab="npm"
npm i eslint-config-typescript-vitnode@canary && npm i eslint-config-typescript-vitnode@canary vitnode-frontend@canary vitnode-shared@canary --workspace=frontend && npm i eslint-config-typescript-vitnode@canary vitnode-backend@canary vitnode-shared@canary --workspace=backend && npm i eslint-config-typescript-vitnode@canary vitnode-shared@canary --workspace=shared
```

</Tabs>
