# (VitNode) AWS S3 / Cloudflare R2 Storage Adapter

This package provides an S3-compatible storage adapter for VitNode file uploads.
A single adapter serves both **AWS S3** and **Cloudflare R2** — R2 only needs a
custom `endpoint`.
