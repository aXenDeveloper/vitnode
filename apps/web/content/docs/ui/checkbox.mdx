## Usage

```tsx
import { AutoForm } from '@vitnode/core/components/form/auto-form'
import { AutoFormCheckbox } from '@vitnode/core/components/form/fields/checkbox'
import { z } from 'zod'

const formSchema = z.object({
  acceptRules: z.boolean().refine((value) => value, {
    message: 'You need to accept the rules to join',
  }),
```

```tsx
<AutoForm
  formSchema={formSchema}
  fields={[
    {
      id: 'acceptRules',
      component: (props) => (
        <AutoFormCheckbox {...props} label="I accept the community rules" />
      ),
    },
  ]}
/>
```

## States

<Preview name="checkbox-states" />

- `indeterminate` draws a dash, for "some selected".
- `disabled` dims it. Add `data-disabled` to the parent [Field](/docs/ui/field)
  to dim the label too.
- `aria-invalid` turns it red. Point `aria-describedby` at the error.

```tsx
<Field data-invalid orientation="horizontal">
  <Checkbox aria-describedby="rules-error" aria-invalid id="rules" />
  <FieldContent>
    <FieldLabel htmlFor="rules">I have read the community rules</FieldLabel>
    <FieldError id="rules-error">Tick this one to post.</FieldError>
  </FieldContent>
</Field>
```

Every checkbox needs a label. The hit area reaches beyond the box, so it's
easy to tap on a phone.
