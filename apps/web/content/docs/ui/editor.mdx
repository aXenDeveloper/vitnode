import { Editor } from "@vitnode/core/components/ui/editor";

The `Editor` is uncontrolled by default - pass `value` as the initial HTML and
listen for changes with `onChange`, which receives the current HTML string:

```tsx
const [content, setContent] = useState("<p>Hello World! 🌎️</p>");

<Editor value={content} onChange={setContent} />;
```

## Writing in the editor

The toolbar keeps the everyday tools one click away and tucks the rest into
menus, so it fits on a single row even in a narrow form:

- **Text style** - paragraph or heading 1–4.
- **Bold** and **italic**, plus a **…** menu with underline, strikethrough,
  inline code, text alignment and _Clear formatting_.
- **Text color**, **lists** (bulleted, numbered and task lists), **link**,
  **emoji**, **table** and **code block**.
- **+ Insert** - quotes, code blocks, tables, dividers, emoji, audio and panels.

### Slash commands

Type <kbd>/</kbd> anywhere to insert a block without reaching for the mouse.
Keep typing to filter (`/tab` finds _Table_), move with the arrow keys and
press <kbd>Enter</kbd>. Your fingers never leave the keyboard - your coffee
stays safe.

The menu searches both the translated block names and English keywords, so
`/table` works in every language.

### Panels

Panels are callouts for things readers should not miss, styled like the
callouts in these docs:

| Panel   | Use it for                   |
| ------- | ---------------------------- |
| Info    | Useful context               |
| Warning | Something to double-check    |
| Error   | A blocker or a real risk     |
| Success | What went right              |

A panel with one paragraph shows it as a muted description. Add a second
paragraph and the first one becomes the title - no extra button, just press
<kbd>Enter</kbd>.

Pick one from **+ Insert** or with `/panel`. Choosing the same panel again
removes it; choosing another kind switches the color. Panels are stored as
plain HTML (`<div data-panel="info">`), so `EditorContent` renders them with
no extra setup.

### Task lists

Task lists store each item's checkbox state, so a list of acceptance criteria
stays ticked after you save. Start one from the toolbar, from `/task`, or by
typing `[ ]` at the start of a line.

### Keyboard shortcuts

| Action           | Shortcut                                             |
| ---------------- | ---------------------------------------------------- |
| Submit the form  | <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>Enter</kbd>      |
| Bold / italic    | <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>B</kbd> / <kbd>I</kbd> |
| Underline        | <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>U</kbd>          |
| Bulleted list    | <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>Shift</kbd> + <kbd>8</kbd> |
| Numbered list    | <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>Shift</kbd> + <kbd>7</kbd> |
| Task list        | <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>Shift</kbd> + <kbd>9</kbd> |
| Undo / redo      | <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>Z</kbd> / <kbd>Shift</kbd> + <kbd>Z</kbd> |

<kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>Enter</kbd> submits the form the editor
sits in, exactly like pressing the submit button. Outside a form it does
nothing.

## Multi-language

Set the `multiLang` prop to edit the content in every enabled language. A
language **select** (shown only when more than one language is enabled) switches
which language you are editing - it does **not** change the app-wide locale,
only the content inside this editor.

The value becomes an array matching the `core_languages_words` table:

```ts
[
  { languageCode: "en", value: "<p>Hello</p>" },
  { languageCode: "pl", value: "<p>Cześć</p>" },
];
```

Declare the field with the `multiLangValueSchema` helper and enable `multiLang`:

```ts
import { multiLangValueSchema } from "@vitnode/core/lib/helpers/multi-lang";

const formSchema = z.object({
  content: multiLangValueSchema({ minLength: 1 }).min(1),
});
```

```tsx
{
  id: "content",
  component: props => <AutoFormEditor {...props} label="Content" multiLang />,
}
```

Persist the array on the backend with `saveLanguageWords`. See
[Auto Form - Multi-language fields](/docs/ui/auto-form#multi-language-fields).

## Rendering Content

Use `EditorContent` to render the stored HTML as read-only content outside of
the editor (e.g. on a public page):

```ts
import { EditorContent } from "@vitnode/core/components/ui/editor-content";
```

```tsx
<EditorContent content="<h2>Title</h2><p>Hello World! 🌎️</p>" />
```
