## Usage

```ts
import { Badge } from '@vitnode/core/components/ui/badge'
```

```tsx
<Badge variant="success">Published</Badge>
```

## Variants

Let the word carry the meaning and the color back it up.

| Variant                           | Use it for                                  |
| --------------------------------- | ------------------------------------------- |
| `default`                         | A prominent, neutral label.                 |
| `secondary` / `outline` / `ghost` | Quiet labels in dense UI like tables.       |
| `link`                            | A label that looks like a text link.        |
| `success`                         | Healthy or done: Published, Active, Paid.   |
| `warning`                         | Needs attention: Pending, Expiring, Draft.  |
| `destructive`                     | Failed or blocked: Failed, Banned, Overdue. |

Status variants share their tint with the matching button, so a `success`
badge and a `success` button read as the same idea.

## With an icon

<Preview name="badge-icon" />

Icons shrink to 12px. Mark them `data-icon="inline-start"` or
`data-icon="inline-end"` to tighten the padding on that side.

```tsx
<Badge variant="success">
  <BadgeCheck data-icon="inline-start" />
  Verified
</Badge>
```

## Counter

<Preview name="badge-counter" />

Numbers are tabular, so counts don't jiggle. Add `min-w-5 px-1` for a round
pill, and `sr-only` text so "8" means something to screen readers.

```tsx
<Badge className="min-w-5 px-1">
  8<span className="sr-only">unread messages</span>
</Badge>
```

## As a link

<Preview name="badge-link" />

Pass `render` to make the badge a link. Links get a hover state.

```tsx
<Badge render={<a href="/tags/announcements" />} variant="secondary">
  #announcements
</Badge>
```
