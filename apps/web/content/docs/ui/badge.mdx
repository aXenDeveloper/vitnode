title: Badge
description: A small label for a status, a count or a tag, in the same variants as the button - and it takes a Lucide icon as a child.
icon: Tag
---

## Preview

<Preview name="badge" />

## Usage

```ts
import { Home } from 'lucide-react'
import { Badge } from '@vitnode/core/components/ui/badge'
```

```tsx
<Badge>
  <Home /> Default
</Badge>
```
