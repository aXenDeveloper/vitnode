## Usage

There's nothing to wire up. Pass `pageInfo` from the API and the table renders
numbered pages, a rows-per-page select (10, 20, 30 or 40) and a "Showing 21–30
of 380" range.

- **Pages are real links.** `?page=3` works with middle-click and "open in new
  tab", while a plain click stays client-side.
- **Phones get a label.** Below `sm`, the numbers collapse to "Page 3 of 38"
  between the arrows.
- **Filters and page size reset to page one.** The old page no longer means
  what it did.
- **Too far lands on the last page.** The API clamps a page past the end, so
  stale links still show rows.

The API does the counting. See [Pagination](/docs/dev/database/pagination) for
the route side, including the index your sorted column needs.
