## Usage

Set the `search` prop to `true` to render a search input above the table. Change the placeholder with `searchPlaceholder`.

```tsx
<DataTable
  id="users-table"
  // [!code ++]
  search
  // [!code ++]
  searchPlaceholder="Search users..."
  columns={[
    { accessorKey: 'name', header: 'Name' },
    { accessorKey: 'email', header: 'Email' },
  ]}
  edges={data.edges}
  pageInfo={data.pageInfo}
  order={{
    defaultOrder: {
      column: 'name',
      order: 'asc',
    },
  }}
/>
```

The input writes the term to the `?search=` query parameter (debounced), and the route loads the matching rows from the API. The API route decides which columns are searched.

<Callout type="info" title="Configure the API route">
  Enabling `search` only renders the input. You must also tell the backend which
  columns to search across - see the [Search](/docs/dev/database/search) guide.
</Callout>
