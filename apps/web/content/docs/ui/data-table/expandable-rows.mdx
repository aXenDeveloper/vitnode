## Usage

Some rows have more to say than a cell can hold - an order's line items, a job's error log, a user's last logins. Pass `expandable` and every row grows a chevron that slides a detail panel open right underneath it. No modal, no new page, no losing your place.

```tsx
<DataTable
  id="orders-table"
  // [!code ++]
  expandable={{
    // [!code ++]
    render: (order) => <OrderDetail order={order} />,
    // [!code ++]
    canExpand: (order) => order.items.length > 0,
    // [!code ++]
  }}
  columns={columns}
  edges={data.edges}
  pageInfo={data.pageInfo}
  order={{
    defaultOrder: {
      column: 'number',
      order: 'asc',
    },
  }}
/>
```

import { TypeTable } from 'fumadocs-ui/components/type-table'

<TypeTable

A few things the table handles for you:

- **Several rows can be open at once.** Open state lives in the component, not the URL, and it is dropped for rows that leave the page when you paginate, search or filter.
- **It is a real button.** The chevron is a `<button>` with `aria-expanded` and `aria-controls`, so Enter and Space work and screen readers announce "Expand row" / "Collapse row". Row clicks from `rowOpens` keep working, because a click on a button never counts as a row click.
- **It plays nice with `bulkActions`.** The chevron column sits right after the selection checkbox.
- **The motion is polite.** The panel eases its height and opacity open in about 300 ms, and with "reduce motion" turned on it simply fades - no sliding around.

<Callout type="info" title="Keep the panel light on data">
  `render` runs on the client as soon as a row opens. If the detail needs data
  the list did not fetch, fetch it inside the panel component (TanStack Query
  caches it), so collapsing and re-opening a row is instant.
</Callout>
