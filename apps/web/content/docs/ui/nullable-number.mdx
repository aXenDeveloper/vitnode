## Preview

<Preview name="nullable-number" />

A [Number Field](/docs/ui/number-field) plus one checkbox, for when the honest
answer is "no limit".

## Usage

```ts
import { z } from 'zod'
import { AutoForm } from '@vitnode/core/components/form/auto-form'
import { AutoFormNullableNumber } from '@vitnode/core/components/form/fields/nullable-number'
```

```tsx
const formSchema = z.object({
  max_members: z.number().int().min(1).nullable().default(10),
})

<AutoForm
  formSchema={formSchema}
  fields={[
    {
      id: 'max_members',
      component: props => (
        <AutoFormNullableNumber
          {...props}
          label="Maximum members"
          min={1}
          toggleLabel="Unlimited"
        />
      ),
    },
  ]}
/>
```

## Value

The value is `number | null`. Checking the box stores `null` and disables the
input. Unchecking it restores the last number. Clearing the input stores `0`.

Back it with `z.number().nullable()`. If the field can be
[hidden](/docs/ui/auto-form#conditional-fields), add a `default` so it never
blocks submission.

## Labels

The second field in the preview uses all three labels:

```tsx
<AutoFormNullableNumber
  {...props}
  label="Auto-logout"
  orLabel="or"
  toggleLabel="Never"
  unitLabel="minutes"
/>
```

Every other prop (`min`, `max`, `step`, `format`, `placeholder`…) goes to the
[Number Field](/docs/ui/number-field#props). Pass `min`/`max` here and in the
schema: the schema validates, the props clamp the buttons and keys.
