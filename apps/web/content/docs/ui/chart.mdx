## Installation

You write plain [TanStack Charts](https://tanstack.com/charts) and borrow the
container, colors, tooltip and legend from VitNode. Every TanStack mark, scale
and transform works out of the box.

## Create a bar chart

A chart is a **definition** (marks, scales, colors) rendered by TanStack's
`Chart` inside VitNode's `ChartContainer`.

```tsx
import type { ChartConfig } from '@vitnode/core/components/ui/chart'

import { barY, defineChart, group } from '@tanstack/charts'
import { Chart } from '@tanstack/charts/react/tooltip'
import { scaleBand } from '@tanstack/charts/scales/band'
import { scaleLinear } from '@tanstack/charts/scales/linear'
import { tooltip } from '@tanstack/charts/tooltip'
import { fold } from '@tanstack/charts/transform/fold'
import {
  chartColor,
  ChartContainer,
  ChartLegend,
  ChartTooltipContent,
} from '@vitnode/core/components/ui/chart'

const chartData = [
  { month: 'January', desktop: 186, mobile: 80 },
  { month: 'February', desktop: 305, mobile: 200 },
]

const chartConfig = {
  desktop: { label: 'Desktop', color: 'var(--chart-1)' },
  mobile: { label: 'Mobile', color: 'var(--chart-2)' },
} satisfies ChartConfig

// One row per bar: { month, device: 'desktop' | 'mobile', visitors }
const rows = fold(chartData, {
  fields: ['desktop', 'mobile'] as const,
  as: { key: 'device', value: 'visitors' },
})

const definition = defineChart({
  marks: [
    barY(rows, {
      x: 'month',
      y: 'visitors',
      color: 'device',
      layout: group(),
      radius: 4,
    }),
  ],
  scales: {
    x: { scale: () => scaleBand().padding(0.2) },
    y: { scale: scaleLinear, nice: true, grid: true, axis: false },
  },
  color: chartColor(chartConfig),
  focus: 'group-x',
  tooltip,
})

export const VisitorsChart = () => (
  <ChartContainer config={chartConfig}>
    <Chart
      ariaLabel="Visitors"
      definition={definition}
      height={280}
      renderTooltipBody={({ points }) => (
        <ChartTooltipContent points={points} />
      )}
    />
    <ChartLegend />
  </ChartContainer>
)
```

- `fold()` turns wide rows into one row per series. TanStack Charts colors and
  groups marks by a field, so the series name has to live in the data.
- `color: 'device'` sends each row through `chartColor(chartConfig)`, which
  paints `desktop` with `--color-desktop`.
- Import `Chart` from `@tanstack/charts/react/tooltip` whenever you pass
  `renderTooltipBody`. The plain `@tanstack/charts/react` entry keeps
  TanStack's built-in tooltip text.

Define charts at module scope. When a definition reads props or state, wrap
it in `useMemo`. A new definition object tells TanStack Charts to redraw.

## Chart config

Each config key matches a series value (`desktop`, `mobile`) or a category
(`general`, `support`). The config holds the words and colors, so your data
stays clean.

```tsx
const chartConfig = {
  desktop: { label: 'Desktop', icon: Monitor, color: 'var(--chart-1)' },
  mobile: {
    label: 'Mobile',
    theme: { light: 'var(--chart-2)', dark: 'var(--chart-4)' },
  },
} satisfies ChartConfig
```

- `label` is what the tooltip and legend show.
- `icon` replaces the color swatch in the tooltip and legend.
- `color` works in both themes. Use `theme` when light and dark need different
  colors.

## Colors

For every config key, `ChartContainer` creates a `--color-<key>` variable
scoped to that chart. There are two ways to use it:

```tsx
// Map a field to colors - the legend and tooltip swatches follow
barY(rows, { x: 'month', y: 'visitors', color: 'device' })
defineChart({ marks, scales, color: chartColor(chartConfig) })

// Or paint one mark directly
lineY(chartData, {
  x: 'day',
  y: 'responseTime',
  stroke: 'var(--color-responseTime)',
})
```

`ChartContainer` also maps TanStack's default palette to `--chart-1` to
`--chart-5`, and styles axes, grid lines, focus rings and tooltips with
VitNode tokens. Charts follow light and dark mode without extra code.

Pick from `--chart-1` to `--chart-5` in order: blue, orange, gray, green, red.
Two or three per chart is plenty. See [Colors](/docs/ui/colors#chart-palette).

## Area chart

<Preview name="chart-area" />

Stack the rows with `stackRowsY()`, then draw an area and a line from the same
endpoints. Gradients are chart resources, so they can read the color variables.

```tsx
import { areaY, defineChart, lineY } from '@tanstack/charts'
import { d3Curve } from '@tanstack/charts/d3/shape'
import { decorative } from '@tanstack/charts/mark/decorative'
import { stackRowsY } from '@tanstack/charts/transform/stack'
import { curveMonotoneX } from 'd3-shape'

const curve = d3Curve(curveMonotoneX)

const rows = stackRowsY(
  fold(chartData, {
    fields: ['upgrades', 'downloads'] as const,
    as: { key: 'kind', value: 'installs' },
  }),
  { x: 'month', y: 'installs', z: 'kind' },
)

const definition = defineChart({
  marks: [
    decorative(
      areaY(rows, {
        x: 'month',
        y1: 'y1',
        y2: 'y2',
        z: 'kind',
        fill: (row) => `url(#fill-${row.kind})`,
        fillOpacity: 1,
        curve,
      }),
    ),
    lineY(rows, { x: 'month', y: 'y2', z: 'kind', curve }),
  ],
  scales: {
    x: { scale: scalePoint },
    y: { scale: scaleLinear, nice: true, grid: true, axis: false },
  },
  color: chartColor(chartConfig),
  gradients: (['downloads', 'upgrades'] as const).map((kind) => ({
    id: `fill-${kind}`,
    y1: 0,
    y2: 1,
    stops: [
      { offset: 0.05, color: `var(--color-${kind})`, opacity: 0.8 },
      { offset: 0.95, color: `var(--color-${kind})`, opacity: 0.1 },
    ],
  })),
  focus: 'group-x',
  tooltip,
})
```

- `decorative()` keeps the area visible but out of hover and keyboard focus,
  so every month shows up in the tooltip once.
- The line sits on the stacked top (`y2`). Pass `valueKey="installs"` to the
  tooltip so it shows each series' own value, not the running total.
- Smooth curves come from `d3-shape`. Install it next to `@tanstack/charts`
  when you want them. Straight segments need nothing extra.

## Line chart

<Preview name="chart-line" />

```tsx
import { crosshair } from '@tanstack/charts/crosshair'

const definition = defineChart({
  marks: [
    crosshair({ x: true, y: false }),
    lineY(chartData, {
      x: 'day',
      y: 'responseTime',
      stroke: 'var(--color-responseTime)',
      points: true,
    }),
  ],
  scales: {
    x: { scale: () => scalePoint().padding(0.3) },
    y: { scale: scaleLinear, nice: true, grid: true, axis: false },
  },
  focus: 'nearest-x',
  maxFocusDistance: Number.POSITIVE_INFINITY,
  tooltip,
})
```

`focus: 'nearest-x'` with an infinite distance snaps to the closest day
anywhere in the plot, and `crosshair()` draws a guide at that day. A single
series has no series field, so name it in the tooltip with
`nameKey="responseTime"`.

## Pie chart

<Preview name="chart-pie" />

Each slice is a row, not a series. `pie()` turns totals into angles, and
`radialArc()` draws them inside `polar()`.

```tsx
import { pie, polar, radialArc } from '@tanstack/charts/polar'

const definition = defineChart({
  marks: [
    polar({
      marks: [
        radialArc(pie(chartData, { value: 'threads' }), {
          innerRadius: ({ radius }) => radius * 0.5,
          color: 'category',
          key: 'category',
        }),
      ],
      scales: { angle: null, radius: null },
    }),
  ],
  scales: { x: null, y: null },
  color: chartColor(chartConfig),
  tooltip,
})

<ChartTooltipContent hideLabel nameKey="category" points={points} valueKey="threads" />
```

Return `0` from `innerRadius` for a full pie instead of a donut.

## Tooltip

`ChartTooltipContent` renders inside TanStack's tooltip and reads labels, icons
and colors from your config. Hover the previews to compare `dashed` (bar),
`dot` (area) and `line` (line).

```tsx
<Chart
  ariaLabel="Visitors"
  definition={definition}
  renderTooltipBody={({ points }) => (
    <ChartTooltipContent indicator="line" points={points} />
  )}
/>
```

Placement and behavior live in the definition. A few useful options:

- `focus: 'group-x'` shows every series at the hovered category.
- `tooltip: { use: tooltip, sort: 'color-domain' }` lists rows in config order.
- `tooltip: { use: tooltip, portal }` (from `@tanstack/charts/tooltip/portal`)
  lets the tooltip escape a card with `overflow: hidden`.

Click or press <kbd>Enter</kbd> to pin a tooltip, <kbd>Esc</kbd> to unpin it.

## Legend

`ChartLegend` is a plain HTML list built from your config, so screen readers
can read it. Put it inside `ChartContainer`, after the chart.

```tsx
<ChartContainer config={chartConfig}>
  <Chart ariaLabel="Threads by category" definition={definition} />
  <ChartLegend />
</ChartContainer>
```

## Size

`Chart` fills the container's width. Set its height with one of:

- `height={280}` - a fixed height, the safest choice for dashboards.
- `aspectRatio={16 / 9}` - height follows the width.

Charts render on the server at `initialWidth` (640px by default), then measure
their real width after hydration.

## Accessibility

- `ariaLabel` is required. Add `ariaDescription` for a sentence about the data.
- Tab to the chart, then use the arrow keys, <kbd>Home</kbd> and <kbd>End</kbd>
  to move between points. The tooltip follows the keyboard.
- Keep a visible heading next to the chart, like a `CardTitle`. Never rely on
  color alone: tooltip and legend labels tell series apart.
- Animations (`svgAnimation: true`) respect `prefers-reduced-motion`.

## Migrate from Recharts

VitNode used Recharts before. The ideas map one to one:

| Recharts                                    | TanStack Charts                                        |
| ------------------------------------------- | ------------------------------------------------------ |
| `<BarChart>` + `<Bar>` children             | `defineChart({ marks: [barY(...)] })`                  |
| Wide rows + one `dataKey` per series        | `fold()` into long rows + `color: 'series'`            |
| `fill="var(--color-desktop)"` on each `Bar` | `color: chartColor(chartConfig)`                       |
| `stackId`                                   | Repeated x values stack by default, or `stackRowsY()`  |
| `<XAxis>` / `<CartesianGrid>`               | `scales.x.axis` / `scales.y.grid`                      |
| `type="monotone"`                           | `curve: d3Curve(curveMonotoneX)`                       |
| `<ChartTooltip content={...} />`            | `tooltip` in the definition + `renderTooltipBody`      |
| `<ChartLegend content={...} />`             | `<ChartLegend />`                                      |
| `accessibilityLayer`, `title`, `desc`       | `ariaLabel`, `ariaDescription` (keyboard is always on) |
| `ChartContainer className="aspect-video"`   | `<Chart height={280} />` or `aspectRatio={16 / 9}`     |

`ChartTooltip` and `ChartLegendContent` are gone: the tooltip is configured in
the definition, and `ChartLegend` is now a component you render directly.
