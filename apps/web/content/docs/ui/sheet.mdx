## Usage

```ts
import { Button } from '@vitnode/core/components/ui/button'
import {
  Sheet,
  SheetClose,
  SheetContent,
  SheetDescription,
  SheetFooter,
  SheetHeader,
  SheetTitle,
  SheetTrigger,
} from '@vitnode/core/components/ui/sheet'
```

```tsx
<Sheet>
  <SheetTrigger render={<Button variant="outline">Notifications</Button>} />
  <SheetContent>
    <SheetHeader>
      <SheetTitle>Notifications</SheetTitle>
      <SheetDescription>Pick what lands in your inbox.</SheetDescription>
    </SheetHeader>
    <SheetFooter>
      <SheetClose render={<Button variant="outline">Done</Button>} />
    </SheetFooter>
  </SheetContent>
</Sheet>
```

`SheetHeader` and `SheetFooter` bring their own padding. Give the content
between them `px-4` to line up.

## Side

<Preview name="sheet-side" />

`side` picks the edge: `right` (default), `left`, `top` or `bottom`. Left and
right sheets take 3/4 of a phone screen and cap at `max-w-sm` from `sm` up.

```tsx
<SheetContent side="left">...</SheetContent>
```

## Sheet or Drawer?

A sheet is a dialog that slides. A [Drawer](/docs/ui/drawer) also follows your
finger and closes with a swipe, which feels better on phones.

## Props

import { TypeTable } from 'fumadocs-ui/components/type-table'

<TypeTable
  type={{
    side: {
      description: 'Edge the sheet slides in from.',
      type: '"top" | "right" | "bottom" | "left"',
      default: '"right"',
    },
    showCloseButton: {
      description: 'Shows the × button in the corner.',
      type: 'boolean',
      default: 'true',
    },
  }}
/>

Both props live on `SheetContent`. `Sheet` takes `open` and `onOpenChange` like
a [Dialog](/docs/ui/dialog).
