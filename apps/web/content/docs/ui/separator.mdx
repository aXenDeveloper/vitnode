## Usage

```ts
import { Separator } from '@vitnode/core/components/ui/separator'
```

```tsx
<Separator />
```

## Vertical

`orientation="vertical"` draws a vertical line at the parent's full height, so
give the row a height:

```tsx
<div className="flex h-5 items-center gap-4">
  <span>Forum</span>
  <Separator orientation="vertical" />
  <span>Blog</span>
</div>
```

## Accessibility

It renders `role="separator"` with the matching `aria-orientation`, so screen
readers know where one group ends.
