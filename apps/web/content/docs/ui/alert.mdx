## Usage

```ts
import {
  Alert,
  AlertDescription,
  AlertTitle,
} from '@vitnode/core/components/ui/alert'
```

```tsx
<Alert variant="warning">
  <AlertTitle>Cron adapter missing</AlertTitle>
  <AlertDescription>
    Scheduled jobs won&apos;t run until you configure one.
  </AlertDescription>
</Alert>
```

Alerts match the callouts in these docs and the
[Editor](/docs/ui/editor#panels) panels, so a warning reads the same
everywhere.

## Variants

- `default` - a neutral note. No icon, just the bar.
- `info` - useful context.
- `success` - something finished and went well.
- `warning` - a non-blocking caution worth acting on.
- `destructive` - an error or a failed action.

Every variant except `default` brings its own icon.

## Screen readers

`warning` and `destructive` get `role="alert"`, so screen readers interrupt to
read them. The rest use `role="status"` and wait their turn. For a static hint
that's on the page from the start, pass `role="note"`:

```tsx
<Alert role="note" variant="warning">
  <AlertTitle>Exports run nightly</AlertTitle>
</Alert>
```

## Custom icon

<Preview name="alert-icon" />

Pass any icon to `icon`, or `null` for none.

```tsx
<Alert icon={<HardDriveIcon />} variant="info">
  <AlertTitle>Storage is connected</AlertTitle>
</Alert>
```

## Dismissible

<Preview name="alert-dismissible" />

`AlertAction` pins a control to the top end corner, and the alert makes room
for it.

```tsx
<Alert variant="warning">
  <AlertTitle>Maintenance tonight at 22:00</AlertTitle>
  <AlertAction>
    <Button aria-label="Dismiss" size="icon-sm" variant="ghost">
      <XIcon />
    </Button>
  </AlertAction>
</Alert>
```
