## Preset palette

<Preview name="color-presets" />

A default swatch plus seven hues and gray, in up to three tones. The default
stores `""` and renders in the theme's text color. Every tone keeps 3:1
contrast on light and dark backgrounds, and a unit test enforces it.

For the palette alone, use `ColorPresetPicker`. The values live in
`@vitnode/core/components/ui/color-presets`.

```ts
import { ColorPresetPicker } from '@vitnode/core/components/ui/color-preset-picker'
```

```tsx
<ColorPresetPicker onChange={setColor} value={color} />
```

The swatches are one radio group, so arrow keys move between them.

## Output format

Presets and the picker store HSL, like `hsl(215, 81%, 52%)`. The text input
stores any CSS color you type. Hex, `rgb()`, `hsl()` and `oklch()` move the
picker; anything else parks it on black.

[react-colorful](https://github.com/omgovich/react-colorful) loads only when the
popover opens.

## Clearing

`allowRemoveColor` adds a "Remove" button that sets `""`. The
[preview](#preview) has it on.

## Editor text color

The [editor](/docs/ui/editor)'s text color action uses the same preset palette,
with no free-form picker. Its popover ends with a "Remove color" button.

## Props

import { TypeTable } from 'fumadocs-ui/components/type-table'

<TypeTable
  type={{
    label: { description: 'Label above the field.', type: 'string' },

      description: 'Show a "Remove" button that clears the value to `""`.',

Other props, like `disabled`, go to the trigger button.
