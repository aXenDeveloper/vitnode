Every component on these pages ships from `@vitnode/core/components/*` - the same
ones the site, the AdminCP and every plugin screen are built from. They are
[Shadcn UI](https://ui.shadcn.com) components on
[Base UI](https://base-ui.com) primitives, styled with
[Tailwind CSS 4](https://tailwindcss.com) and driven by semantic design tokens
(`bg-background`, `text-foreground`), so a component picks up light and dark mode
without being told.

```tsx
import { Button } from "@vitnode/core/components/ui/button";

<Button>Save changes</Button>;
```
