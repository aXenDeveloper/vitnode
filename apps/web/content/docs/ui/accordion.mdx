## Usage

```ts
import {
  Accordion,
  AccordionContent,
  AccordionItem,
  AccordionTrigger,
} from '@vitnode/core/components/ui/accordion'
```

```tsx
<Accordion defaultValue={['register']}>
  <AccordionItem value="register">
    <AccordionTrigger>How do I create an account?</AccordionTrigger>
    <AccordionContent>
      <p>Click Sign up in the top bar and fill in your email.</p>
    </AccordionContent>
  </AccordionItem>
</Accordion>
```

`defaultValue` and `value` are arrays of item values, even when only one item
can be open.

## Multiple

<Preview name="accordion-multiple" />

By default, opening an item closes the others. `multiple` lets several stay
open.

```tsx
<Accordion defaultValue={['kind', 'search']} multiple>
```

## Find in page

With `hiddenUntilFound`, closed panels stay in the DOM and the browser's

<kbd>Ctrl</kbd> + <kbd>F</kbd> can find and open them. Great for long FAQs.

```tsx
<Accordion hiddenUntilFound>
```
