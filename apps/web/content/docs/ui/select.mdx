## Usage

import { Tab, Tabs } from 'fumadocs-ui/components/tabs'

<Tabs items={['Auto Form', 'Manual']}>
  <Tab value="Auto Form">

Options come from the `z.enum`. `labels` names them; a value without a label
shows as is.

```ts
import { z } from 'zod'
import { AutoForm } from '@vitnode/core/components/form/auto-form'
import { AutoFormSelect } from '@vitnode/core/components/form/fields/select'

const formSchema = z.object({
  visibility: z.enum(['public', 'members', 'staff']).default('public'),
})
```

```tsx
<AutoForm
  formSchema={formSchema}
  fields={[
    {
      id: 'visibility',
      component: (props) => (
        <AutoFormSelect
          {...props}
          label="Visibility"
          labels={[
            { value: 'public', label: 'Everyone' },
            { value: 'members', label: 'Signed-in members' },
            { value: 'staff', label: 'Staff only' },
          ]}
        />
      ),
    },
  ]}
/>
```

  </Tab>

  <Tab value="Manual">

```tsx
import {
  Select,
  SelectContent,
  SelectItem,
  SelectTrigger,
  SelectValue,
} from '@vitnode/core/components/ui/select'

const items = [
  { label: 'Everyone', value: 'public' },
  { label: 'Staff only', value: 'staff' },
]

;<Select items={items}>
  <SelectTrigger>
    <SelectValue placeholder="Pick visibility" />
  </SelectTrigger>
  <SelectContent>
    {items.map((item) => (
      <SelectItem key={item.value} value={item.value}>
        {item.label}
      </SelectItem>
    ))}
  </SelectContent>
</Select>
```

Pass `items` to `Select` so `SelectValue` shows the label. Without it you get
the raw `value`.

</Tabs>

## Groups and sizes

<Preview name="select-groups" />

`SelectGroup` + `SelectLabel` add headings, `SelectSeparator` draws a line.
`SelectTrigger` takes `size="sm"` for toolbars and filters.

```tsx
<SelectTrigger size="sm">
  <SelectValue />
</SelectTrigger>
<SelectContent>
  <SelectGroup>
    <SelectLabel>Members</SelectLabel>
    <SelectItem value="newest">Newest first</SelectItem>
  </SelectGroup>
  <SelectSeparator />
</SelectContent>
```

Give a manual select a label, for example with `aria-labelledby` on the
trigger. `AutoFormSelect` does it for you.

## Motion and touch

- The chevron flips and the list scales in from the trigger. Reduced motion
  turns both off.
- On touch screens the trigger's tap area grows to 44px and options get taller.
- Scrolling a long list never drags the page along.

## Props

import { TypeTable } from 'fumadocs-ui/components/type-table'

<TypeTable
  type={{
    label: {
      description: 'Shown above the select.',
      type: 'ReactNode',
    },
    description: {
      description: 'Shown below the select.',
      type: 'ReactNode',
    },
    labels: {
      description: 'Readable label for each enum value.',
      type: '{ value: string; label: string }[]',
      default: '[]',
    },
    placeholder: {
      description: 'Shown while nothing is picked.',
      type: 'string',
      default: '"Select an option"',
    },
  }}
/>

`AutoFormSelect` also passes [Base UI Select](https://base-ui.com/react/components/select#api-reference)
root props through, like `disabled` and `onValueChange`.
