## Usage

import { Tab, Tabs } from 'fumadocs-ui/components/tabs'

<Tabs items={['Auto Form', 'Manual']}>
  <Tab value="Auto Form">

```tsx
import { AutoForm } from '@vitnode/core/components/form/auto-form'
import { AutoFormRadioGroup } from '@vitnode/core/components/form/fields/radio-group'
import { z } from 'zod'

const formSchema = z.object({
  sort: z.enum(['latest', 'top', 'unanswered']).default('latest'),
})
```

```tsx
<AutoForm
  formSchema={formSchema}
  fields={[
    {
      id: 'sort',
      component: (props) => (
        <AutoFormRadioGroup
          {...props}
          label="Default sort"
          labels={[
            {
              value: 'latest',
              label: 'Latest activity',
              description: 'New replies float up.',
            },
            { value: 'top', label: 'Most liked' },
            { value: 'unanswered', label: 'Unanswered first', disabled: true },
          ]}
        />
      ),
    },
  ]}
/>
```

Options come from the `z.enum()`. `labels` only adds text: an enum value
without a label shows the raw value.

  </Tab>
  <Tab value="Manual">

```tsx
import {
  Field,
  FieldContent,
  FieldDescription,
  FieldLabel,
} from '@vitnode/core/components/ui/field'
import {
  RadioGroup,
  RadioGroupItem,
} from '@vitnode/core/components/ui/radio-group'
```

```tsx
<RadioGroup aria-label="Default sort" defaultValue="latest">
  <Field orientation="horizontal">
    <RadioGroupItem id="latest" value="latest" />
    <FieldContent>
      <FieldLabel htmlFor="latest">Latest activity</FieldLabel>
      <FieldDescription>New replies float up.</FieldDescription>
    </FieldContent>
  </Field>
  <Field data-disabled orientation="horizontal">
    <RadioGroupItem disabled id="unanswered" value="unanswered" />
    <FieldLabel htmlFor="unanswered">Unanswered first</FieldLabel>
  </Field>
</RadioGroup>
```

  </Tab>
</Tabs>

Arrow keys move between options and select them. Tab leaves the group.

## Blocks

<Preview name="radio-group-blocks" />

`variant="blocks"` turns each option into a clickable card. It's built from
[Field choice cards](/docs/ui/field#choice-cards).

```tsx
<AutoFormRadioGroup
  {...props}
  label="Registration"
  labels={labels}
  variant="blocks"
/>
```
