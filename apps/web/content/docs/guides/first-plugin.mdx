This is the short version: generate a plugin and see its page. The [Learn lessons](/docs/dev) build the same `site-notes` plugin into a real feature.

## Before you begin

- A VitNode app created with **Turborepo** turned on, running locally. [Setup](/docs/dev/setup) walks through it.

<Steps>

<Step>

### Generate the plugin

From the workspace root:

<Tabs groupId="package-manager" persist items={["bun", "pnpm", "npm"]} label="Generate the plugin">

```bash tab="bun"
bun create vitnode-app@canary site-notes --plugin
```

```bash tab="pnpm"
pnpm create vitnode-app@canary site-notes --plugin
```

```bash tab="npm"
npm create vitnode-app@canary site-notes -- --plugin
```

</Tabs>

The generator creates `plugins/site-notes` and registers it in your app's VitNode configs, so there is nothing to enable by hand.

</Step>

<Step>

### Run it

<Tabs groupId="package-manager" persist items={["bun", "pnpm", "npm"]} label="Start the app">

```bash tab="bun"
bun run dev
```

```bash tab="pnpm"
pnpm dev
```

```bash tab="npm"
npm run dev
```

</Tabs>

</Step>

</Steps>

## Check the result

Open `http://localhost:3000/site-notes`. The page comes from `plugins/site-notes/src/pages/home-page.tsx`, and `http://localhost:3000/api/site-notes/hello` answers from the plugin's API.
