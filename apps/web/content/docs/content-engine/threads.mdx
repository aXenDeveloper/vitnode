Comments are records of their own: a comment content type that points at the article it answers. The `thread` option gives that type a route that returns an article's comments a page at a time, and the server checks where every comment may go. This page adds flat comments under each article; [Replies](/docs/content-engine/threads-frontend) then lets comments answer each other.

This continues the article page from [Reports](/docs/content-engine/reports). It uses `@tanstack/react-query`, added in [Create form](/docs/content-engine/public-write-frontend#add-tanstack-query-to-the-plugin).

<Step>

### Define the comment type

Create `src/content/comment.ts`. This is the complete file:

```ts title="plugins/newsroom/src/content/comment.ts"
import { defineContentType, field } from "@vitnode/core/content";

import { articleContentType } from "@/content/article";

export const commentContentType = defineContentType({
  id: "newsroom.comment",
  tableName: "newsroom_comments",

  fields: {
    slug: field.slug({ generated: true }),
    body: field.richText({ required: true }),
    author: field.user(),
    article: field.relation({
      target: () => articleContentType,
      required: true,
      onDelete: "cascade",
    }),
    parent: field.relation({
      self: true,
      nullable: true,
      onDelete: "set null",
    }),
  },

  publication: true,
  visibility: true,

  publicApi: {
    path: "comments",
    fields: ["id", "slug", "body", "article", "parent", "publishedAt"],
    people: ["author"],
  },

  publicWrite: {
    ownership: { field: "author" },
    create: { fields: ["body", "article", "parent"], status: "published" },
    update: { fields: ["body"] },
  },

  thread: { parent: "parent", root: "article", maxDepth: 1 },

  admin: { path: "newsroom/comments", titleField: "slug" },
});
```

- **`article`** is the comment's **root**: the record it belongs to. It must be a required relation to another content type. `onDelete: "cascade"` removes the comments with their article.
- **`parent`** is the comment being answered, or `null`. `thread` requires it even for flat comments; `maxDepth: 1` keeps every comment top level for now.
- **`slug`** with `generated: true` gets a random token, because a comment has no title. The public API needs exactly one slug.
- **`publicWrite`** lets members post `body` under an `article`. A comment's place is fixed when it is written, so `parent` and `article` are never in `update.fields`.
- **`visibility`** lets moderators hide a comment, and **`admin`** gives staff a list of comments in the AdminCP.

### Read the comments

Create `src/pages/comment-data.ts`. All loaded pages of one article's comments live in one infinite query, so refreshing it reloads every page in order:

```ts title="plugins/newsroom/src/pages/comment-data.ts"
import { infiniteQueryOptions } from "@tanstack/react-query";
import {
  zodContentPublicPerson,
  zodRichTextDocument,
} from "@vitnode/core/content";
import { fetcher } from "@vitnode/core/tanstack/fetcher";
import { z } from "zod";

import { manifest } from "@/manifest.gen";

/** Top-level comments per page. The thread route accepts 1 to 50. */
const COMMENTS_PAGE_SIZE = 20;

/** One comment as `publicApi.fields` and `people` return it. */
const zodComment = z.object({
  author: zodContentPublicPerson.nullable().catch(null),
  body: zodRichTextDocument,
  id: z.number(),
  publishedAt: z.string().nullable(),
});

const zodCommentPage = z.object({
  items: z.array(
    z.object({
      depth: z.number(),
      id: z.number(),
      parentId: z.number().nullable(),
      record: zodComment.nullable(),
      removed: z.boolean(),
    }),
  ),
  pageInfo: z.object({
    endCursor: z.string().nullable(),
    hasNextPage: z.boolean(),
    totalCount: z.number(),
  }),
  replyCount: z.number(),
  truncated: z.boolean(),
});

export type CommentPage = z.infer<typeof zodCommentPage>;

export type CommentItem = CommentPage["items"][number];

export type ArticleComment = NonNullable<CommentItem["record"]>;

const fetchCommentPage = async (articleId: number, after?: string) => {
  const res = await fetcher({
    plugin: manifest.id,
    method: "get",
    module: "content/comments",
    path: "/thread",
    args: {
      query: {
        root: String(articleId),
        first: COMMENTS_PAGE_SIZE,
        ...(after ? { after } : {}),
      },
    },
  });
  if (res.status !== 200) throw new Error("Loading the comments failed.");

  // The thread route types `record` loosely, so parse it once here.
  return zodCommentPage.parse(await res.json());
};

export const commentsQueryKey = (articleId: number) =>
  [manifest.id, "comments", articleId] as const;

/** Every loaded page under one key, so a refetch reloads them all in order. */
export const commentsQueryOptions = (articleId: number) =>
  infiniteQueryOptions({
    getNextPageParam: (last: CommentPage) =>
      last.pageInfo.hasNextPage
        ? (last.pageInfo.endCursor ?? undefined)
        : undefined,
    initialPageParam: undefined as string | undefined,
    queryFn: async ({ pageParam }) =>
      await fetchCommentPage(articleId, pageParam),
    queryKey: commentsQueryKey(articleId),
  });
```

- `GET /comments/thread?root={articleId}` returns up to `first` top-level comments, oldest first. `endCursor` asks for the next page.
- `items` is flat: each comment has `depth`, `parentId` and `record`. With `maxDepth: 1`, every item is top level.
- The thread route types `record` loosely, so `zodCommentPage` checks the fields `publicApi` returns once, here. `author` comes from `people` as a small public profile, or `null` for a deleted account.
- `replyCount` counts every public comment, for the "2 comments" heading.

### Ask who may edit

Create `src/pages/comment-permissions.ts`, like the article's in [Permissions](/docs/content-engine/public-permissions):

```ts title="plugins/newsroom/src/pages/comment-permissions.ts"
import { useContentPermissions } from "@vitnode/core/tanstack/content";
import { fetcher } from "@vitnode/core/tanstack/fetcher";

import { manifest } from "@/manifest.gen";

/** What the visitor may do with each comment on screen: `canEdit`, `canReport`. */
export const useCommentPermissions = (ids: readonly number[]) =>
  useContentPermissions({
    ids,
    queryKey: [manifest.id, "comments"],
    fetch: async request => {
      const res = await fetcher({
        plugin: manifest.id,
        method: "get",
        module: "content/comments",
        path: "/permissions",
        args: { query: { ids: request.join(",") } },
      });
      if (res.status !== 200) throw new Error("Loading permissions failed.");

      return await res.json();
    },
  });
```

### Write the composer

Create `src/pages/comment-composer.tsx`. One form posts a new comment or saves an edit:

```tsx title="plugins/newsroom/src/pages/comment-composer.tsx"
import {
  AutoForm,
  type AutoFormOnSubmit,
  AutoFormSubmitButton,
} from "@vitnode/core/components/form/auto-form";
import { AutoFormEditor } from "@vitnode/core/components/form/fields/editor";
import { Button } from "@vitnode/core/components/ui/button";
import {
  emptyRichTextDocument,
  isRichTextEmpty,
  type RichTextDocument,
  zodRichTextDocument,
} from "@vitnode/core/content";
import { useContentPublicWrite } from "@vitnode/core/tanstack/content";
import { fetcher } from "@vitnode/core/tanstack/fetcher";
import { useTranslations } from "use-intl";
import { z } from "zod";

import { manifest } from "@/manifest.gen";

export type CommentComposerProps = {
  label: string;
  onCancel?: () => void;
  /** Called after a save, with whether it waits for a moderator. */
  onDone: (outcome: { edited: boolean; pending: boolean }) => Promise<void>;
} & (
  | { articleId: number; mode: "create"; parentId: null | number }
  | { body: RichTextDocument; commentId: number; mode: "edit" }
);

const createSchema = (body: RichTextDocument, required: string) =>
  z.object({
    body: zodRichTextDocument
      .refine(doc => !isRichTextEmpty(doc), required)
      .default(body),
  });

type CommentSchema = ReturnType<typeof createSchema>;

const CommentComposer = (props: CommentComposerProps) => {
  const t = useTranslations("newsroom.comments.form");
  const write = useContentPublicWrite({ fields: ["body"] });

  const onSubmit: AutoFormOnSubmit<CommentSchema> = async ({ body }, form) => {
    const saved =
      props.mode === "edit"
        ? await write.submit(
            form,
            async () =>
              await fetcher({
                plugin: manifest.id,
                method: "patch",
                module: "content/comments",
                path: "/{id}",
                args: {
                  params: { id: props.commentId },
                  body: { values: { body } },
                },
              }),
          )
        : await write.submit(
            form,
            async () =>
              await fetcher({
                plugin: manifest.id,
                method: "post",
                module: "content/comments",
                path: "/",
                args: {
                  body: {
                    values: {
                      article: props.articleId,
                      body,
                      parent: props.parentId,
                    },
                  },
                },
              }),
          );
    if (!saved) return;

    await props.onDone({
      edited: props.mode === "edit",
      pending: saved.approval?.status === "pending",
    });
  };

  return (
    <AutoForm
      aria-label={props.label}
      className="flex flex-col gap-3"
      fields={[
        {
          id: "body",
          component: fieldProps => (
            <AutoFormEditor {...fieldProps} format="json" label={props.label} />
          ),
        },
      ]}
      formSchema={createSchema(
        props.mode === "edit" ? props.body : emptyRichTextDocument(),
        t("required"),
      )}
      layout={fields => <>{fields.body}</>}
      onSubmit={onSubmit}
    >
      <div className="flex flex-wrap items-center gap-2">
        <AutoFormSubmitButton>
          {props.mode === "edit" ? t("save") : t("submit")}
        </AutoFormSubmitButton>
        {props.onCancel ? (
          <Button onClick={props.onCancel} type="button" variant="ghost">
            {t("cancel")}
          </Button>
        ) : null}
      </div>
    </AutoForm>
  );
};

export default CommentComposer;
```

- **A new comment** posts `{ values: { article, body, parent } }`; `parent: null` answers the article itself. The server fills `author`.
- **An edit** sends only `body`, to `PATCH /{id}`.
- `useContentPublicWrite` shows refusals, such as an expired session, as toasts. `onDone` reports whether the comment waits for a moderator.
- The file has a default export because the section loads it with `lazy`: the editor is heavy, and most readers never write.

### Render the comments

Create `src/pages/comment-section.tsx`:

```tsx title="plugins/newsroom/src/pages/comment-section.tsx"
import {
  useQueryClient,
  useSuspenseInfiniteQuery,
} from "@tanstack/react-query";
import { RichTextContent } from "@vitnode/core/components/rich-text";
import { Button, buttonVariants } from "@vitnode/core/components/ui/button";
import { Skeleton } from "@vitnode/core/components/ui/skeleton";
import {
  type RichTextDocument,
  zodRichTextDocument,
} from "@vitnode/core/content";
import { useSessionQuery } from "@vitnode/core/tanstack/auth";
import { fetcher } from "@vitnode/core/tanstack/fetcher";
import { HrefLink } from "@vitnode/core/tanstack/link";
import { lazy, Suspense, useMemo, useState } from "react";
import { toast } from "sonner";
import { useTranslations } from "use-intl";
import { z } from "zod";

import { manifest } from "@/manifest.gen";

import type { CommentComposerProps } from "./comment-composer";
import type { ArticleComment } from "./comment-data";

import { commentsQueryKey, commentsQueryOptions } from "./comment-data";
import { useCommentPermissions } from "./comment-permissions";

// The editor is heavy and most readers never write, so it loads on demand.
const CommentComposer = lazy(async () => await import("./comment-composer"));

const Composer = (props: CommentComposerProps) => (
  <Suspense fallback={<Skeleton className="h-40 w-full rounded-lg" />}>
    <CommentComposer {...props} />
  </Suspense>
);

const zodProposal = z
  .object({ body: zodRichTextDocument.optional() })
  .catch({});

/** Loads the latest text of a comment before editing it. */
const useOpenEditor = () => {
  const t = useTranslations("core.global.content_write");

  return async (commentId: number): Promise<null | RichTextDocument> => {
    const res = await fetcher({
      plugin: manifest.id,
      method: "get",
      module: "content/comments",
      path: "/{id}/edit",
      args: { params: { id: commentId } },
    });
    if (res.status !== 200) {
      const reason =
        res.status === 401
          ? "unauthenticated"
          : res.status === 403
            ? "forbidden"
            : res.status === 404
              ? "not_found"
              : "unknown";
      toast.error(t("title"), { description: t(reason) });

      return null;
    }

    const record = await res.json();
    const { approval } = record;
    // A pending edit opens on the proposal, not on the live text.
    const proposed =
      approval?.status === "pending" && approval.kind === "edit"
        ? zodProposal.parse(approval.values ?? {})
        : {};

    return proposed.body ?? record.values.body;
  };
};

const Comment = ({
  canEdit,
  comment,
  onSaved,
}: {
  canEdit: boolean;
  comment: ArticleComment;
  onSaved: CommentComposerProps["onDone"];
}) => {
  const t = useTranslations("newsroom.comments");
  const openEditor = useOpenEditor();
  const [editing, setEditing] = useState<null | RichTextDocument>(null);
  const [isOpening, setIsOpening] = useState(false);

  return (
    <div className="flex flex-col gap-2">
      <p className="text-sm font-medium">
        {comment.author?.name ?? t("someone")}
      </p>

      {editing ? (
        <Composer
          body={editing}
          commentId={comment.id}
          label={t("form.edit_label")}
          mode="edit"
          onCancel={() => {
            setEditing(null);
          }}
          onDone={async outcome => {
            setEditing(null);
            await onSaved(outcome);
          }}
        />
      ) : (
        <RichTextContent
          className="leading-relaxed text-pretty"
          content={comment.body}
        />
      )}

      {canEdit && !editing ? (
        <Button
          className="self-start"
          isLoading={isOpening}
          onClick={async () => {
            setIsOpening(true);
            try {
              setEditing(await openEditor(comment.id));
            } finally {
              setIsOpening(false);
            }
          }}
          size="sm"
          variant="ghost"
        >
          {t("edit")}
        </Button>
      ) : null}
    </div>
  );
};

export const CommentSection = ({
  articleId,
  articleSlug,
}: {
  articleId: number;
  articleSlug: string;
}) => {
  const t = useTranslations("newsroom.comments");
  const queryClient = useQueryClient();
  const session = useSessionQuery();
  const [composerKey, setComposerKey] = useState(0);
  const comments = useSuspenseInfiniteQuery(commentsQueryOptions(articleId));

  const { pages } = comments.data;
  const items = useMemo(() => pages.flatMap(page => page.items), [pages]);
  const permissions = useCommentPermissions(
    items.flatMap(item => (item.record ? [item.id] : [])),
  );

  const onSaved: CommentComposerProps["onDone"] = async ({
    edited,
    pending,
  }) => {
    if (pending) {
      toast.info(t("pending.title"), { description: t("pending.desc") });
    } else {
      const key = edited ? "edited" : "created";
      toast.success(t(`${key}.title`), { description: t(`${key}.desc`) });
    }
    // Refetches every loaded page in order, with the new count.
    await queryClient.invalidateQueries({
      queryKey: commentsQueryKey(articleId),
    });
  };

  return (
    <section aria-labelledby="comments-title" className="flex flex-col gap-6">
      <h2 className="text-xl font-semibold text-balance" id="comments-title">
        {t("title", { count: pages[0]?.replyCount ?? 0 })}
      </h2>

      {items.length === 0 ? (
        <p className="text-muted-foreground leading-relaxed">{t("empty")}</p>
      ) : (
        <ol aria-busy={comments.isFetching} className="flex flex-col gap-6">
          {items.map(item =>
            item.record ? (
              <li key={item.id}>
                <Comment
                  canEdit={permissions.of(item.id).canEdit}
                  comment={item.record}
                  onSaved={onSaved}
                />
              </li>
            ) : null,
          )}
        </ol>
      )}

      {comments.hasNextPage ? (
        <Button
          className="self-start"
          disabled={comments.isFetching}
          isLoading={comments.isFetchingNextPage}
          onClick={async () => {
            const next = await comments.fetchNextPage();
            if (next.isError) {
              toast.error(t("load_failed.title"), {
                description: t("load_failed.desc"),
              });
            }
          }}
          variant="outline"
        >
          {t("load_more")}
        </Button>
      ) : null}

      {session.data?.user ? (
        <Composer
          articleId={articleId}
          // A new key gives the next comment a fresh, empty editor.
          key={composerKey}
          label={t("form.label")}
          mode="create"
          onDone={async outcome => {
            setComposerKey(composerKey + 1);
            await onSaved(outcome);
          }}
          parentId={null}
        />
      ) : (
        <HrefLink
          className={buttonVariants({
            className: "self-start",
            variant: "outline",
          })}
          href={`/login?returnTo=${encodeURIComponent(`/news/${articleSlug}`)}`}
        >
          {t("sign_in")}
        </HrefLink>
      )}
    </section>
  );
};
```

- **`useSuspenseInfiniteQuery`** reads the pages the article's loader warms in the next step, so the comments are in the server-rendered HTML.
- **Permissions** are asked once for every loaded comment that has a record.
- **Edit** loads `GET /comments/{id}/edit` first, so the form opens on the latest text, or on a pending proposal in `approval.values`. The button shows a spinner while it loads.
- **Load more comments** calls `fetchNextPage` with the last cursor. It shows its own spinner and is disabled during any fetch, so a double click never loads a page twice.
- **`onSaved`** picks the toast and invalidates the article's comment query. TanStack Query refetches every loaded page from the first, so a new or edited comment and the heading's count update together. A new key gives the composer a fresh, empty editor.
- **Guests** see a sign-in link instead of the composer.

</Step>

import { z } from "zod";

import { articleContentType } from "@/content/article";

const zodArticle = z.object({
  body: zodRichTextDocument,
  id: z.number(),
  publishedAt: z.string().nullable(),
  slug: z.string(),
  title: z.string(),
});

const loadArticle = async (slug: string) => {
  const [resolution, detail] = await Promise.all([
    fetcher({
      plugin: manifest.id,
      method: "get",
      module: "content/news",
      path: "/delivery/resolve/{slug}",
      args: { params: { slug: encodeURIComponent(slug) } },
    }),
    fetcher({
      plugin: manifest.id,
      method: "get",
      module: "content/news",
      path: "/{slug}",
      args: { params: { slug: encodeURIComponent(slug) } },
    }),
  ]);

  if (resolution.status !== 200) {
    throw new Error(
      `Resolving the article "${slug}" answered ${resolution.status}.`,
    );
  }

  return contentDeliveryPage({
    item: detail.status === 200 ? zodArticle.parse(await detail.json()) : null,
    resolution: await resolution.json(),
  });
};

type ArticlePageData = Awaited<ReturnType<typeof loadArticle>>;

export const route = defineRoute({
  load: async ({ context, params }) => {
    const page = await loadArticle(params.slug);
    // The first page of comments arrives with the article's HTML.
    await context.queryClient.infiniteQuery(commentsQueryOptions(page.item.id));

    return page;
  },

  head: ({ loaderData }) =>
    contentDeliveryPageHead(loaderData?.metadata, {
      title: loaderData?.item.title,
    }),
});

/** Asked in the browser, so the cached page stays the same for everyone. */
const ArticleActions = ({ id, title }: { id: number; title: string }) => {
  const t = useTranslations("newsroom.articles");
  const { canEdit, canReport } = useArticlePermissions([id]).of(id);

  return (
    <div className="flex flex-wrap gap-2">
      {canEdit ? (
        <HrefLink
          className={buttonVariants({ size: "sm", variant: "outline" })}
          href={`/news/${id}/edit`}
        >
          {t("edit_link")}
        </HrefLink>
      ) : null}
      {canReport ? (
        <ReportButton
          preview={{ title }}
          target={contentTarget(manifest.id, articleContentType, id)}
          typeLabel={t("report_type")}
        />
      ) : null}
    </div>
  );
};

const ArticlePage = ({
  loaderData: { item },
}: PluginRoutePageProps<ArticlePageData>) => (
  <article className="container mx-auto flex max-w-3xl flex-col gap-6 px-4 py-8">
    <header className="flex flex-col gap-2">
      <h1 className="text-3xl font-semibold tracking-tight text-balance">
        {item.title}
      </h1>
      {item.publishedAt ? (
        <span className="text-muted-foreground text-sm">
          <DateFormat date={item.publishedAt} />
        </span>
      ) : null}
      <ArticleActions id={item.id} title={item.title} />
    </header>

    <RichTextContent
      className="leading-relaxed text-pretty"
      content={item.body}
    />

    <CommentSection articleId={item.id} articleSlug={item.slug} />
  </article>
);

export default ArticlePage;

## Authentication and approval

- **Signed out.** `POST /comments` answers `401`; the section never offers the composer to guests.
- **Approval.** `create.status: "published"` makes comments live at once. With `"draft"`, or when the article's container holds new posts for [approval](/docs/content-engine/approvals), the response has `approval.status: "pending"` and the comment appears after a moderator approves it. The section's toast already says so.
- **Placement.** The server checks every comment's `article` and `parent`: the article must be public, the parent must belong to the same article, and nothing may nest deeper than `maxDepth`. A broken rule answers `400` with an issue on `parent`, which the composer shows as a toast.
- **Hidden articles.** A comment is only as public as its article. Once the article is unpublished or hidden, its comments drop out of the thread and their own routes answer `404`.
