This page adds **Edit** to the comments a visitor may change, opens an editor in place, and refreshes the thread after a save. Authors edit their own comments; moderators with `can_edit` edit anyone's.

This continues the working comment section from [Comments](/docs/content-engine/threads). Its comment type already has `update: { fields: ["body"] }`, so `PATCH /comments/{id}` and `GET /comments/{id}/edit` exist.

<Steps>

<Step>

### Ask who may edit

Create `src/pages/comment-permissions.ts`. This is the complete file, like the article's in [Permissions](/docs/content-engine/public-permissions):

```ts title="plugins/newsroom/src/pages/comment-permissions.ts"
import { useContentPermissions } from "@vitnode/core/tanstack/content";
import { fetcher } from "@vitnode/core/tanstack/fetcher";

import { manifest } from "@/manifest.gen";

/** What the visitor may do with each comment on screen: `canEdit`, `canReport`. */
export const useCommentPermissions = (ids: readonly number[]) =>
  useContentPermissions({
    ids,
    queryKey: [manifest.id, "comments"],
    fetch: async request => {
      const res = await fetcher({
        plugin: manifest.id,
        method: "get",
        module: "content/comments",
        path: "/permissions",
        args: { query: { ids: request.join(",") } },
      });
      if (res.status !== 200) throw new Error("Loading permissions failed.");

      return await res.json();
    },
  });
```

`GET /comments/permissions` answers `canEdit` per comment for the visitor who asks: the author while the rules allow it, or a moderator with `can_edit`. `queryKey` starts with the comments' prefix, so invalidating `[manifest.id, "comments"]` refreshes the answers too.

</Step>

### Write the editor

Create `src/pages/comment-editor.tsx`. This is the complete file. It edits one comment's body and reports whether the save waits for a moderator:

```tsx title="plugins/newsroom/src/pages/comment-editor.tsx"
import {
  AutoForm,
  type AutoFormOnSubmit,
  AutoFormSubmitButton,
} from "@vitnode/core/components/form/auto-form";
import { AutoFormEditor } from "@vitnode/core/components/form/fields/editor";
import { Button } from "@vitnode/core/components/ui/button";
import {
  isRichTextEmpty,
  type RichTextDocument,
  zodRichTextDocument,
} from "@vitnode/core/content";
import { useContentPublicWrite } from "@vitnode/core/tanstack/content";
import { fetcher } from "@vitnode/core/tanstack/fetcher";
import { useTranslations } from "use-intl";
import { z } from "zod";

import { manifest } from "@/manifest.gen";

export interface CommentEditorProps {
  /** The comment's latest text, from `GET /comments/{id}/edit`. */
  body: RichTextDocument;
  commentId: number;
  label: string;
  onCancel: () => void;
  /** Called after a save, with whether it waits for a moderator. */
  onSaved: (pending: boolean) => Promise<void>;
}

const createSchema = (body: RichTextDocument, required: string) =>
  z.object({
    body: zodRichTextDocument
      .refine(doc => !isRichTextEmpty(doc), required)
      .default(body),
  });

const CommentEditor = ({
  body,
  commentId,
  label,
  onCancel,
  onSaved,
}: CommentEditorProps) => {
  const t = useTranslations("newsroom.comments.form");
  const write = useContentPublicWrite({ fields: ["body"] });

  const onSubmit: AutoFormOnSubmit<ReturnType<typeof createSchema>> = async (
    values,
    form,
  ) => {
    const saved = await write.submit(
      form,
      async () =>
        await fetcher({
          plugin: manifest.id,
          method: "patch",
          module: "content/comments",
          path: "/{id}",
          args: { params: { id: commentId }, body: { values } },
        }),
    );
    if (!saved) return;

    await onSaved(saved.approval?.status === "pending");
  };

  return (
    <AutoForm
      aria-label={label}
      className="flex flex-col gap-3"
      fields={[
        {
          id: "body",
          component: fieldProps => (
            <AutoFormEditor {...fieldProps} format="json" label={label} />
          ),
        },
      ]}
      formSchema={createSchema(body, t("required"))}
      layout={fields => <>{fields.body}</>}
      onSubmit={onSubmit}
    >
      <div className="flex flex-wrap items-center gap-2">
        <AutoFormSubmitButton>{t("save")}</AutoFormSubmitButton>
        <Button onClick={onCancel} type="button" variant="ghost">
          {t("cancel")}
        </Button>
      </div>
    </AutoForm>
  );
};

export default CommentEditor;
```

- **The request** sends only `body` to `PATCH /comments/{id}`. Members can never move a comment, because `article` and `parent` are not in `update.fields`.
- **`write.submit`** shows a refusal as a toast and returns `null`, so the editor stays open with the text.
- **`onSaved(pending)`** is `true` only when the comment lives in a container that holds edits for approval. For newsroom comments it is always `false`.

```tsx title="plugins/newsroom/src/pages/comment-section.tsx (excerpt)"
/** A comment, with Edit for the visitors who may use it. */
const CommentItem = ({
  canEdit,
  comment,
  onSaved,
}: {
  canEdit: boolean;
  comment: ArticleComment;
  onSaved: CommentEditorProps["onSaved"];
}) => {
  const t = useTranslations("newsroom.comments");
  const tWrite = useTranslations("core.global.content_write");
  const [editing, setEditing] = useState<null | RichTextDocument>(null);
  const [isOpening, setIsOpening] = useState(false);

  // Opens the editor on the comment's latest text, not on the cached copy.
  const openEditor = async () => {
    setIsOpening(true);
    try {
      const res = await fetcher({
        plugin: manifest.id,
        method: "get",
        module: "content/comments",
        path: "/{id}/edit",
        args: { params: { id: comment.id } },
      });
      if (res.status !== 200) {
        const reason =
          res.status === 401
            ? "unauthenticated"
            : res.status === 403
              ? "forbidden"
              : res.status === 404
                ? "not_found"
                : "unknown";
        toast.error(tWrite("title"), { description: tWrite(reason) });

        return;
      }

      setEditing((await res.json()).values.body);
    } finally {
      setIsOpening(false);
    }
  };

  if (editing) {
    return (
      <div className="flex flex-col gap-2">
        <p className="text-sm font-medium">
          {comment.author?.name ?? t("someone")}
        </p>
        <Suspense fallback={<Skeleton className="h-40 w-full rounded-lg" />}>
          <CommentEditor
            body={editing}
            commentId={comment.id}
            label={t("form.edit_label")}
            onCancel={() => {
              setEditing(null);
            }}
            onSaved={async pending => {
              setEditing(null);
              await onSaved(pending);
            }}
          />
        </Suspense>
      </div>
    );
  }

  return (
    <div className="flex flex-col gap-2">
      <CommentBody comment={comment} />
      {canEdit ? (
        <Button
          className="self-start"
          isLoading={isOpening}
          onClick={openEditor}
          size="sm"
          variant="ghost"
        >
          {t("edit")}
        </Button>
      ) : null}
    </div>
  );
};
```

- **Edit** first loads `GET /comments/{id}/edit`, so the editor opens on the latest saved text, not on the copy the thread cached. The button shows a spinner while it loads, so a second click cannot open it twice.
- A refusal, such as a session that expired in the meantime, becomes a toast with core's message, and the comment stays as it was.
- While editing, the comment's text is replaced by the editor, with **Save** and **Cancel**.

- **`onEdited`** invalidates the article's comment query, which refetches every loaded page, so the new text shows in place.

```tsx title="plugins/newsroom/src/pages/comment-section.tsx"
import { useInfiniteQuery, useQueryClient } from "@tanstack/react-query";
import { RichTextContent } from "@vitnode/core/components/rich-text";
import { Button, buttonVariants } from "@vitnode/core/components/ui/button";
import { Skeleton } from "@vitnode/core/components/ui/skeleton";
import { type RichTextDocument } from "@vitnode/core/content";
import { useSessionQuery } from "@vitnode/core/tanstack/auth";
import { fetcher } from "@vitnode/core/tanstack/fetcher";
import { HrefLink } from "@vitnode/core/tanstack/link";
import { lazy, Suspense, useMemo, useState } from "react";
import { toast } from "sonner";
import { useTranslations } from "use-intl";

import { manifest } from "@/manifest.gen";

import type { CommentComposerProps, CommentOutcome } from "./comment-composer";
import type { ArticleComment } from "./comment-data";
import type { CommentEditorProps } from "./comment-editor";

import { commentsQueryKey, commentsQueryOptions } from "./comment-data";
import { useCommentPermissions } from "./comment-permissions";

// The editor is heavy and most readers never write, so it loads on demand.
const CommentComposer = lazy(async () => await import("./comment-composer"));
const CommentEditor = lazy(async () => await import("./comment-editor"));

const Composer = (props: CommentComposerProps) => (
  <Suspense fallback={<Skeleton className="h-40 w-full rounded-lg" />}>
    <CommentComposer {...props} />
  </Suspense>
);

/** Who wrote a comment, and what they said. */
const CommentBody = ({ comment }: { comment: ArticleComment }) => {
  const t = useTranslations("newsroom.comments");

  return (
    <div className="flex flex-col gap-2">
      <p className="text-sm font-medium">
        {comment.author?.name ?? t("someone")}
      </p>
      <RichTextContent
        className="leading-relaxed text-pretty"
        content={comment.body}
      />
    </div>
  );
};

/** A comment, with Edit for the visitors who may use it. */
const CommentItem = ({
  canEdit,
  comment,
  onSaved,
}: {
  canEdit: boolean;
  comment: ArticleComment;
  onSaved: CommentEditorProps["onSaved"];
}) => {
  const t = useTranslations("newsroom.comments");
  const tWrite = useTranslations("core.global.content_write");
  const [editing, setEditing] = useState<null | RichTextDocument>(null);
  const [isOpening, setIsOpening] = useState(false);

  // Opens the editor on the comment's latest text, not on the cached copy.
  const openEditor = async () => {
    setIsOpening(true);
    try {
      const res = await fetcher({
        plugin: manifest.id,
        method: "get",
        module: "content/comments",
        path: "/{id}/edit",
        args: { params: { id: comment.id } },
      });
      if (res.status !== 200) {
        const reason =
          res.status === 401
            ? "unauthenticated"
            : res.status === 403
              ? "forbidden"
              : res.status === 404
                ? "not_found"
                : "unknown";
        toast.error(tWrite("title"), { description: tWrite(reason) });

        return;
      }

      setEditing((await res.json()).values.body);
    } finally {
      setIsOpening(false);
    }
  };

  if (editing) {
    return (
      <div className="flex flex-col gap-2">
        <p className="text-sm font-medium">
          {comment.author?.name ?? t("someone")}
        </p>
        <Suspense fallback={<Skeleton className="h-40 w-full rounded-lg" />}>
          <CommentEditor
            body={editing}
            commentId={comment.id}
            label={t("form.edit_label")}
            onCancel={() => {
              setEditing(null);
            }}
            onSaved={async pending => {
              setEditing(null);
              await onSaved(pending);
            }}
          />
        </Suspense>
      </div>
    );
  }

  return (
    <div className="flex flex-col gap-2">
      <CommentBody comment={comment} />
      {canEdit ? (
        <Button
          className="self-start"
          isLoading={isOpening}
          onClick={openEditor}
          size="sm"
          variant="ghost"
        >
          {t("edit")}
        </Button>
      ) : null}
    </div>
  );
};

export const CommentSection = ({
  articleId,
  articleSlug,
}: {
  articleId: number;
  articleSlug: string;
}) => {
  const t = useTranslations("newsroom.comments");
  const queryClient = useQueryClient();
  const session = useSessionQuery();
  const [composerKey, setComposerKey] = useState(0);
  const comments = useInfiniteQuery(commentsQueryOptions(articleId));

  const pages = comments.data?.pages;
  const items = useMemo(
    () => pages?.flatMap(page => page.items) ?? [],
    [pages],
  );
  // One request for every comment on screen, batched by the hook.
  const permissions = useCommentPermissions(
    items.flatMap(item => (item.record ? [item.id] : [])),
  );

  const onPosted = async (outcome: CommentOutcome) => {
    if (outcome !== "published") {
      // Not in the public thread, so there is nothing to refresh.
      toast.info(t(`${outcome}.title`), { description: t(`${outcome}.desc`) });

      return;
    }

    toast.success(t("created.title"), { description: t("created.desc") });
    // Refetches every loaded page in order, with the new count.
    await queryClient.invalidateQueries({
      queryKey: commentsQueryKey(articleId),
    });
  };

  const onEdited = async (pending: boolean) => {
    if (pending) {
      toast.info(t("edit_pending.title"), {
        description: t("edit_pending.desc"),
      });
    } else {
      toast.success(t("edited.title"), { description: t("edited.desc") });
    }
    await queryClient.invalidateQueries({
      queryKey: commentsQueryKey(articleId),
    });
  };

  return (
    <section aria-labelledby="comments-title" className="flex flex-col gap-6">
      <h2 className="text-xl font-semibold text-balance" id="comments-title">
        {t("title", { count: pages?.[0]?.replyCount ?? 0 })}
      </h2>

      {comments.isPending ? (
        <div aria-busy="true" className="flex flex-col gap-4">
          <span className="sr-only" role="status">
            {t("loading")}
          </span>
          {[0, 1].map(key => (
            <div className="flex flex-col gap-2" key={key}>
              <Skeleton className="h-4 w-32" />
              <Skeleton className="h-4 w-full" />
            </div>
          ))}
        </div>
      ) : comments.isError && items.length === 0 ? (
        <div className="flex flex-col items-start gap-3">
          <p className="text-muted-foreground leading-relaxed" role="alert">
            {t("load_failed.desc")}
          </p>
          <Button
            isLoading={comments.isFetching}
            onClick={async () => {
              await comments.refetch();
            }}
            variant="outline"
          >
            {t("retry")}
          </Button>
        </div>
      ) : items.length === 0 ? (
        <p className="text-muted-foreground leading-relaxed">{t("empty")}</p>
      ) : (
        <ol aria-busy={comments.isFetching} className="flex flex-col gap-6">
          {items.map(item =>
            item.record ? (
              <li key={item.id}>
                <CommentItem
                  canEdit={permissions.of(item.id).canEdit}
                  comment={item.record}
                  onSaved={onEdited}
                />
              </li>
            ) : null,
          )}
        </ol>
      )}

      {comments.hasNextPage ? (
        <Button
          className="self-start"
          disabled={comments.isFetching}
          isLoading={comments.isFetchingNextPage}
          onClick={async () => {
            const next = await comments.fetchNextPage();
            if (next.isError) {
              toast.error(t("load_failed.title"), {
                description: t("load_failed.desc"),
              });
            }
          }}
          variant="outline"
        >
          {t("load_more")}
        </Button>
      ) : null}

      {session.data?.user ? (
        <Composer
          articleId={articleId}
          // A fresh key gives the next comment an empty editor.
          key={composerKey}
          label={t("form.label")}
          onPosted={async outcome => {
            setComposerKey(key => key + 1);
            await onPosted(outcome);
          }}
          parentId={null}
        />
      ) : (
        <HrefLink
          className={buttonVariants({
            className: "self-start",
            variant: "outline",
          })}
          href={`/login?returnTo=${encodeURIComponent(`/news/${articleSlug}`)}`}
        >
          {t("sign_in")}
        </HrefLink>
      )}
    </section>
  );
};
```

## Two saves of the same comment

Newsroom comments have no `editorial`, so they have no `version`. `PATCH /comments/{id}` takes `{ "values": { "body": ... } }` and nothing else: when two tabs save the same comment, both answer `200` and the last save wins. Sending an `expectedVersion` anyway answers `400` with `Unrecognized key: "expectedVersion"`.

For short comments that is usually fine. To stop silent overwrites, add `editorial: true` to the comment type and migrate. Every comment then gets a `version`, `GET /{id}/edit` returns it, and a stale save answers `409 CONTENT_VERSION_CONFLICT`. Pass `version` and `latestVersion` to `useContentPublicWrite`, send `expectedVersion` from `write.submit`, and render `write.conflict` above the editor, as the article's [Edit form](/docs/content-engine/public-write-edit#handle-version-conflicts) does.
