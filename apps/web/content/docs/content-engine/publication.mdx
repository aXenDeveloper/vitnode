`publication` gives every record two states: **Draft** and **Published**. Drafts stay private, and only staff with the publish permission can make a record public. Turn it on before anything else on the public side, because the [public API](/docs/content-engine/public-api) only ever returns published records.

<Steps>

<Step>

### Turn it on

Add one line to the definition:

```ts title="plugins/example/src/content/article.ts"
export const articleContentType = defineContentType({
  id: "example.article",
  tableName: "example_articles",
  fields: {
    title: field.text({ required: true }),
    slug: field.slug({ source: "title" }),
  },
  publication: true, // [!code ++]
});
```

This adds a `status` column (`draft` or `published`), a `publishedAt` date, a `can_publish` permission and **Publish** and **Unpublish** buttons in the AdminCP.

</Step>

<Step>

### Name the permission

```json title="plugins/example/src/locales/en.json"
{
  "@vitnode/example:article:can_publish": "Publish and unpublish articles"
}
```

</Step>

<Step>

### Migrate

Run this from the workspace root while `pnpm dev` is running:

<Tabs groupId="package-manager" persist items={["bun", "pnpm", "npm"]} label="Migrate the database">

```bash tab="bun"
bun run db:migrate
```

```bash tab="pnpm"
pnpm db:migrate
```

```bash tab="npm"
npm run db:migrate
```

</Tabs>

Existing rows become drafts. `pnpm dev` picks up the new option by itself.

</Step>

</Steps>

## What a reader sees

| The record is              | The public API answers            |
| -------------------------- | --------------------------------- |
| A draft                    | `404`, like a slug that never existed |
| Published with a future `publishedAt` | `404` until that moment   |
| Published                  | The record                        |

The API never says whether a draft exists. To publish later on a schedule, or to share a draft with someone before it goes live, add [`editorial`](/docs/content-engine/editorial).

Open **AdminCP → Example → Articles**. New articles show a **Draft** badge. Click the paper plane **Publish** button at the end of a row:
