---
title: Facebook
description: Integrate Facebook Single Sign-On (SSO) in your application.
---

<Steps>
<Step>

## Sign in to Discord

Go to [Facebook Developers](https://developers.facebook.com/) and sign in.

</Step>
<Step>

## Create a new application

Click on the `Create App` button to create a new application.

</Step>
<Step>

## Add use cases

Chose `Authenticate and request data from users with Facebook Login` as the use case.

</Step>
<Step>

## Get the App ID and App Secret

After creating the application, go to `Settings => Basic` to get the `App ID` and `App Secret`. Save them for later.

</Step>
<Step>

## Environment Variables (.env)

Add the `App ID` and `App Secret` to your `.env` file.

```bash
FACEBOOK_CLIENT_ID={app-id}
FACEBOOK_CLIENT_SECRET={app-secret}
```

</Step>
<Step>

## Configuration in VitNode

Register the Facebook SSO adapter in your API config.

```ts title="src/vitnode.api.config.ts"
// [!code ++]
import { FacebookSSOApiPlugin } from '@vitnode/core/api/adapters/sso/facebook';
import { buildApiConfig } from '@vitnode/core/vitnode.config';

export const vitNodeApiConfig = buildApiConfig({
  plugins: [],
  // [!code ++]
  authorization: {
    // [!code ++]
    ssoAdapters: [
      // [!code ++]
      FacebookSSOApiPlugin({
        // [!code ++]
        clientId: process.env.FACEBOOK_CLIENT_ID,
        // [!code ++]
        clientSecret: process.env.FACEBOOK_CLIENT_SECRET,
        // [!code ++]
      }),
      // [!code ++]
    ],
    // [!code ++]
  },
});
```

<Callout type="info" title="Registering it with the variables unset is safe">
  Each adapter defaults `clientId` and `clientSecret` to `""` and only fails when
  somebody actually tries that provider. So the list is what your API
  *supports*; the environment decides what works.
</Callout>

</Step>

</Steps>
