---
title: Discord
description: Integrate Discord Single Sign-On (SSO) in your application.
---

<Steps>
<Step>

## Sign in to Discord

Go to [Discord Developer Portal](https://discord.com/developers/applications) and sign in.

</Step>
<Step>

## Create a new application

Click on the `New Application` button to create a new application.

</Step>
<Step>

## Redirect URL

Go to `OAuth2` page and inside the `Redirects` section, add the redirect URL.

<Callout title="redirect_uri">
  Your redirect URL should be `https://your-domain.com/login/sso/discord`.
</Callout>

</Step>
<Step>

## Get the Client ID and Client Secret

After creating the application, you will get the `Client ID` and `Client Secret`. Save them for later.

</Step>

<Step>

## Environment Variables (.env)

Add the `Client ID` and `Client Secret` to your `.env` file.

```bash
DISCORD_CLIENT_ID=XXX
DISCORD_CLIENT_SECRET=XXX
```

</Step>

<Step>

## Configuration in VitNode

Register the Discord SSO adapter in your API config.

```ts title="src/vitnode.api.config.ts"
// [!code ++]
import { DiscordSSOApiPlugin } from '@vitnode/core/api/adapters/sso/discord';
import { buildApiConfig } from '@vitnode/core/vitnode.config';

export const vitNodeApiConfig = buildApiConfig({
  plugins: [],
  // [!code ++]
  authorization: {
    // [!code ++]
    ssoAdapters: [
      // [!code ++]
      DiscordSSOApiPlugin({
        // [!code ++]
        clientId: process.env.DISCORD_CLIENT_ID,
        // [!code ++]
        clientSecret: process.env.DISCORD_CLIENT_SECRET,
        // [!code ++]
      }),
      // [!code ++]
    ],
    // [!code ++]
  },
});
```

<Callout type="info" title="Registering it with the variables unset is safe">
  Each adapter defaults `clientId` and `clientSecret` to `""` and only fails when
  somebody actually tries that provider. So the list is what your API
  *supports*; the environment decides what works.
</Callout>

</Step>

<Step>

## Test the SSO

Go to the login page and click on the `Discord` button to test the SSO.

</Step>

</Steps>
