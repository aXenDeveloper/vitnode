VitNode checks once a day whether a newer version of core or any installed plugin is published, and whether the version you run is affected by a published security update. The results appear in **AdminCP → System → Plugins**.

Each package says where its **update manifest** lives - a public JSON file on GitHub Raw or any other HTTPS host. VitNode reads those files from the server. It does not ask npm, and it does not install, download or change anything.

## What the checks can and cannot tell you

- **Informational only.** A check never installs an update or edits your dependencies. You upgrade the way you always do, then rebuild and redeploy.
- **Only what publishers declare.** A package without an update source shows a _No update source_ badge. Private and local plugins work exactly as before.
- **Not a vulnerability scanner.** A security warning means a publisher listed your installed version in a security update. No warning is not proof a version is secure, and dependencies of your plugins are not checked at all. Keep using `pnpm audit` or your usual scanner for those.
