## Usage

In this example, we will show you how to use captcha in your forms. We will use the `AutoForm` component to render the form and handle the captcha validation.

<Steps>
<Step>

### Activate captcha in route

Add `withCaptcha` to your route config to enable captcha validation for this route.

```ts title="plugins/{plugin_name}/src/routes/example.ts"
import { buildRoute } from "@vitnode/core/api/lib/route";

export const exampleRoute = buildRoute({
  pluginId: CONFIG_PLUGIN.pluginId,
  route: {
    method: "post",
    description: "Create a new user",
    path: "/sign_up",
    withCaptcha: true, // [!code ++]
  },
  handler: async c => {},
});
```

</Step>
<Step>

### Read the captcha config

The public site key comes from the middleware config - one anonymous, public read
that is the same answer for every visitor. It is a TanStack Query definition, so
warm it in the route's `loader` and read it back in the component:

```tsx title="apps/web/src/routes/_main/sign-up.tsx"
import { createFileRoute } from "@tanstack/react-router";
import { middlewareConfigQueryOptions } from "@vitnode/core/tanstack/auth"; // [!code ++]

export const Route = createFileRoute("/_main/sign-up")({
  loader: async ({ context }) =>
    await context.queryClient.ensureQueryData(middlewareConfigQueryOptions()), // [!code ++]
  component: SignUpRoute,
});

const SignUpRoute = () => {
  const { data } = useSuspenseQuery(middlewareConfigQueryOptions()); // [!code ++]

  return <FormSignUp captcha={data.captcha} />;
};
```

<Callout type="info" title="If the read fails, the widget is absent">
  The fallback config carries no site key, so a form rendered from it submits an
  empty token and the API answers `400`. Degraded, but never a silent success -
  nothing is created and nothing is claimed to have been.
</Callout>

</Step>
<Step>

### Use in form

Get the `captcha` config from the props and pass it to the `AutoForm` component. This will render the captcha widget in your form.

```tsx title="plugins/{plugin_name}/src/views/sign-up/sign-up.tsx"
import { AutoForm } from "@vitnode/core/components/form/auto-form";

export const FormSignUp = ({
  captcha, // [!code ++]
}: {
  captcha: z.infer<typeof routeMiddlewareSchema>["captcha"]; // [!code ++]
}) => {
  return (
    <AutoForm<typeof formSchema>
      captcha={captcha} // [!code ++]
      fields={[]}
      formSchema={formSchema}
    />
  );
};
```

### Submit form with captcha

In your form submission handler, you can get the `captchaToken` from the form submission context and pass it to your mutation API.

```tsx title="plugins/{plugin_name}/src/views/sign-up/sign-up.tsx"
import {
  AutoForm,
  type AutoFormOnSubmit, // [!code ++]
} from "@vitnode/core/components/form/auto-form";

export const FormSignUp = ({
  captcha,
}: {
  captcha: z.infer<typeof routeMiddlewareSchema>["captcha"];
}) => {
  const onSubmit: AutoFormOnSubmit<typeof formSchema> = async (
    values,
    form,
    { captchaToken }, // [!code ++]
  ) => {
    // Call your mutation API with captcha token
    await mutationApi({
      ...values,
      captchaToken, // [!code ++]
    });

    // Handle success or error
  };

  return (
    <AutoForm<typeof formSchema>
      captcha={captcha}
      fields={[]}
      onSubmit={onSubmit} // [!code ++]
      formSchema={formSchema}
    />
  );
};
```

Then pass `captchaToken` through to your mutation. `AutoForm` hands it to
`onSubmit`; the fetcher forwards it to the API as a header, which is what the
`withCaptcha` route verifies.

```ts title="plugins/{plugin_name}/src/views/sign-up/mutation-api.ts"
import type { z } from "zod";

import { fetcherClient } from "@vitnode/core/lib/fetcher-client";

export const mutationApi = async ({
  captchaToken, // [!code ++]
  ...input
}: // [!code ++]
z.infer<typeof zodSignUpSchema> & { captchaToken: string }) => {
  const res = await fetcherClient(usersModuleRef, {
    path: "/sign_up",
    method: "post",
    module: "users",
    captchaToken, // [!code ++]
    args: {
      body: input,
    },
  });

  if (res.status !== 201) {
    return { error: await res.text() };
  }

  const data = await res.json();

  return { data };
};
```
