Writing CRUD boilerplate for plugins — Drizzle tables, Zod schemas, Hono routes, permissions, data tables, auto-forms, and events — takes a lot of time.

The **Content Engine** generates all of it from a single client-safe declaration:

```ts title="src/content/article.ts"
import { defineContentType, field } from "@vitnode/core/content";

export const articleContentType = defineContentType({
  id: "example.article",
  tableName: "example_articles",
  fields: {
    title: field.text({ required: true, minLength: 3, maxLength: 200 }),
    code: field.text({ required: true, maxLength: 100, unique: true }),
    status: field.enum({ values: ["draft", "published"], defaultValue: "draft" }),
    publishedAt: field.dateTime({ nullable: true }),
    author: field.user(),
  },
  admin: {
  },
});
```

## What You Get

A single definition gives you:
- **Database Table**: Dedicated `example_articles` Postgres table with primary keys, indexes, and standard Drizzle migrations.
- **Zod Schemas**: Pre-built schemas for create, update, select, filters, ordering, and forms.
- **Typed Service**: Self-validating service methods (`findById`, `findMany`, `create`, `update`, `delete`).
- **Staff Permissions**: Automatic staff permission checks (`can_view`, `can_create`, `can_edit`, `can_delete`, `can_publish`).
- **Zero-Code AdminCP**: Fully interactive list, search, sorting, and form dialogs without writing a single page or form component.
- **Typed Events**: `content.example.article.created`, `.updated`, and `.deleted` event hooks.

## How the Three Files Fit Together

Content Engine keeps definitions separate from database and UI logic so your browser bundle stays lightweight while backend APIs gain full access to Drizzle ORM:

| File | Purpose | Why It's Separate |
| :--- | :--- | :--- |
| **`src/content/article.ts`** | Definition | **Client-Safe**. Imports `zod` only. Shared between browser and server without dragging Drizzle ORM to the client. |
| **`src/database/articles.ts`** | Database Model | **Server-Only**. Calls `createContentModel` to generate raw Drizzle tables (`.table`) and typed CRUD service methods (`.service(c)`). |
| **`src/config.tsx` & `src/api/`** | Integration | **App Registration**. Registers zero-code AdminCP management screens (`contentTypeAdmin`) and secure backend routes (`buildContentAdminModule`). |
